# 📱 NSE Scanner Pro - Trading PWA

Professional NSE Stock Scanner with Triple-Layer Strategy.

## 🚀 Features

- 📊 **Live Dashboard** with today's signals
- 📈 **Top Movers** below ₹100
- 🔔 **Active Signals** with entry/SL/targets
- 📋 **Stock Watchlist** (85+ verified stocks)
- 📊 **Performance Analytics** with win rate, profit factor
- ⚙️ **Settings** for capital/risk management
- 🌙 **Dark Mode** by default
- 📱 **Mobile-First** responsive design
- 💾 **Offline Support** (works without internet)
- ⚡ **Install on Phone** like a real app!

## 🌐 Deployment - GitHub Pages (FREE)

### Step 1: Create New Repository

```
1. Go to github.com
2. Click "New repository"
3. Name: nse-trading-app
4. Make it Public (required for free GitHub Pages)
5. Click "Create repository"
```

### Step 2: Upload All Files

```
Upload these files to the repo:
✅ index.html
✅ styles.css
✅ app.js
✅ manifest.json
✅ service-worker.js
✅ README.md
```

### Step 3: Enable GitHub Pages

```
1. Go to repo Settings
2. Click "Pages" in left sidebar
3. Under "Source", select "main" branch
4. Click "Save"
5. Wait 2-3 minutes
```

### Step 4: Access Your App

```
Your app URL will be:
https://YOUR_USERNAME.github.io/nse-trading-app/

Example: 
https://prashant251997.github.io/nse-trading-app/
```

## 📱 Install on Phone

### Android (Chrome):
```
1. Open URL in Chrome
2. Tap menu (3 dots)
3. Tap "Add to Home Screen"
4. App icon appears on home screen!
```

### iPhone (Safari):
```
1. Open URL in Safari
2. Tap Share button
3. Tap "Add to Home Screen"
4. App icon appears on home screen!
```

## 🎨 Customization

### Change Capital/Risk Settings:
- Open the app
- Tap "Settings" in bottom nav
- Adjust capital and risk %
- Tap "Save Settings"

### Add More Stocks:
- Edit `app.js`
- Add to `STOCKS_BELOW_100` array
- Re-upload to GitHub
